# RumiStack 1.3.0

## Multi-runtime project recognition

Project Hub recognises common Python, .NET, Go, Rust and Java project manifests and labels them in the project list. It gives clear guidance that these projects can be stored and organized, but are not yet supported by the automatic dependency installer or project runner.

The existing Node.js workflow remains unchanged. Detection is read-only and does not execute project scripts, package managers, build tools or runtime commands.
